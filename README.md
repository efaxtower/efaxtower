## 🚀 Sobre mí

Desarrollador autodidacta de 18 años, apasionado por la arquitectura de software y el diseño de sistemas escalables. Lo que comenzó como curiosidad se convirtió en la construcción de sistemas que hoy usan personas reales: desde el sistema de panadería de mi papá hasta un supermercado online con microservicios en PHP puro.

**"No sé programar"** - dice el que tiene 6 microservicios funcionando con API Gateway, autenticación por API Key y un carrito de compras 🤡

Mi enfoque no es solo escribir código, sino **entender los fundamentos**: cómo fluyen los datos, cómo escalar un sistema, cómo tomar decisiones arquitectónicas basadas en el contexto real del negocio.

## 🏗️ Proyectos Destacados

### 🛒 **SindroMerchado** - Supermercado Online con Microservicios

> *"Si no sabes cómo funciona un sistema grande, constrúyelo tú mismo"*

Arquitectura de microservicios en PHP puro con API Gateway, autenticación por API Key y 6 servicios independientes. Diseñado para un negocio real que necesita separar la lógica de carnicería (peso), estantes (unidades), administración y clientes.

**Decisiones técnicas que tomé:**
- **API Gateway como único punto de entrada** - Centraliza autenticación y enrutamiento
- **Bases de datos separadas por servicio** - Cada microservicio tiene su propia BD para evitar acoplamiento
- **Carrito en localStorage + WhatsApp** - Porque no toda solución necesita un carrito con sesiones; a veces, la simplicidad es la mejor arquitectura

📌 **Estado:** 68% funcional (pendiente carnicería y estantes)

> *"Mi papá lo usa todos los días"*

### 💻 **Beep Jesus Pro v3.0.1** - Reproductor MIDI en Linux

> *"Porque mi PC debe sonar como la Gata Bajo la Lluvia al encender"*

Script en Bash que convierte archivos MIDI a frecuencias compatibles con el beep de Linux. Incluye un transformador que parsea las notas y las reproduce con el buzzer del sistema.

**Características técnicas:**
- Conversor MIDI → Frecuencias (usando `midi2beep` o similar)
- Ejecución automática al inicio del sistema
- Personalización total de canciones

## 📊 Mi filosofía de desarrollo

> **"El código es solo la punta del iceberg. Lo importante está debajo: la arquitectura, las decisiones de diseño y el porqué de cada elección."**

### ¿Cómo construyo?
1. **Entiendo el problema** - ¿Qué necesita realmente el negocio?
2. **Diseño la arquitectura** - ¿Microservicios? ¿Monolito? ¿API Gateway?
3. **Escribo código** - Usando todas las herramientas a mi alcance (incluyendo IA)
4. **Refactorizo** - Porque el código bueno se escribe dos veces

### ¿Por qué uso IA?
Porque sé exactamente qué pedirle y por qué. No es "escribir código por mí", es "acelerar mi pensamiento". Como un arquitecto que usa AutoCAD - el programa dibuja, pero el diseño es mío.
